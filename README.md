# ReadingAI

Automatický generátor čtenářských deníků pomocí Gemma 4 a DuckDuckGo search.

## Požadavky

- Python 3.10+
- Google AI Studio API klíč (zdarma na [aistudio.google.com](https://aistudio.google.com))

## Instalace

1. Naklonuj repozitář
2. Nainstaluj závislosti:
```bash
pip install -r requirements.txt
```
3. Vlož API klíč do .env
